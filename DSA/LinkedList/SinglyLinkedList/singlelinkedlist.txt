//Linked list is a linear Data Structure where elements are arranged in a sequential order
//Each element is connected to previous and next node
//Data is traversed in single run from one end to another.
//Memory is usually allocated in contiguous blocks (except linked list).

// Contiguous blocks means memory locations that are next to each other, without any gaps between them.
// which stores data in a contiguous memory location just Arrays and Vectors
// in Linked list each node points to the next node in the sequence so you can traverse from the first ode to the last nodein order, one step at a time.
// so linked list are linear->because you can move through them in a single straight sequence, even if the actual memory layout isn't straight
// in linked list we can't access elements directly like arrays arr[4]. we need to traverse using head to access the elements in linked list.
// linked list is dynamic at run time which can be resizable like vector.
// they are 3 type
//1. Single Linked list
//2.Double Linked list
//3. CircularLinked list

// Important Concepts (Asked in Interviews)
// Concept	Description
// Reverse a linked list	Iterative & recursive ways
// Detect a cycle (loop)	Use Floyd’s Cycle Detection (slow & fast pointer)
// Find middle of linked list	Slow-fast pointer technique
// Merge two sorted linked lists	Like merge step in merge sort
// Remove Nth node from end	Two-pointer technique
// Find intersection of two lists	Length-based or two-pointer approach
// Palindrome linked list	Reverse half and compare
