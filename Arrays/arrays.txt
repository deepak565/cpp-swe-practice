========================================Arrays:=======================================
1.Definition:
-----------
An Array is an collection of elements of the same Data type, stored in contiguous memory location
and accessed using an index.

Example:
--------
int arr[5] = {1,2,3,4,5};

->index starts at 0
->fixed in size(can't change dynamically)
->stored contiguous in memory location

2.Array Declaration and initliazation
-------------------------------------

int arr[5];  //uninitlialized
int arr[] = {1,2,3,4,5}; // size auto detected
int arr[5] = {1,2};  // remaining values with 0

4- Types of Arrays:
------------------

| Type                   | Description            | Example                   |
| ---------------------- | ---------------------- | ------------------------- |
| 1D Array               | Single row of elements | `int arr[5];`             |
| 2D Array               | Matrix-like            | `int matrix[3][3];`       |
| 3D Array               | 3D data storage        | `int arr[2][3][4];`       |
| Dynamic Array          | Allocated in heap      | `int* arr = new int[n];`  |
| STL Array              | Fixed-size container   | `std::array<int, 5> arr;` |
| Vector (Dynamic Array) | Resizable container    | `std::vector<int> v;`     |

Arrays are const and can't be resizable at run -time if need to resize need to use Vector

1.Static Array(Fixed size known at compile time.):-
int arr[5]; ->static array memory in stack

2.dynamic array(Size decided at runtime using heap memory.)
int *arr = new arr[5]; ->dynamic array memory in heap

3.Multidimensional Array(Used for matrices, grids, etc.)
int arr[3][3] = {{1,2,3},{4,5,6},{7,8,9}};
cout << arr[1][2]; // 6

4.jaggered Array(Array of pointers, where each row has a different length.)
int *arr[3];
arr = new int[3];
arr1 = new int[4];
arr2 = new int[5];

->Arrays decay to pointers when passed to functions.

->Multi -Dimensional Array
--------------------------
int arr[2][3] = {{1,2,3}, {4,5,6}};


Pointers and Arrays
-------------------
arr is a pointer to the first element.
*(arr + i) == arr[i]
arr + i gives address of ith element.

Accessing elements:-
--------------------
cout << arr[1];     // using index
cout << *(arr + 1); // using pointer

Pointer and Array Relationship
int arr[3] = {10, 20, 30};
int* p = arr;
cout << *(p + 1); // 20

✅ arr and &arr[0] give same address.
🚫 But arr is not a pointer variable — it’s a constant address.

Array Decay

When passed to a function, arrays decay to a pointer to the first element.
Hence, sizeof(arr) inside a function gives size of pointer, not entire array.
