======================Strings===================================================
String:-
=======
String is a sequence of characters stored in a memory

C++ provide 2 main ways of handling string
1.C-style string ->Based on character Array
2.C++ std::string(from <string>) ->object-oriented, safer and most powerfull

2.1 C-style Strings:-
=====================
Defined using char arrays and terminated with a null character '\0'.

char name[] = "Deepak";

equivalent to

char name[] = {'D', 'e', 'e', 'p', 'a', 'k', '\0'};
Stored in stack (if local) or static memory if global.
===========================================================
| Function              | Description                     |
| --------------------- | ------------------------------- |
| `strlen(str)`         | Returns length (excluding '\0') |
| `strcpy(dest, src)`   | Copies string                   |
| `strcat(dest, src)`   | Concatenates                    |
| `strcmp(str1, str2)`  | Compares                        |
| `strchr(str, ch)`     | Finds character                 |
| `strstr(str, substr)` | Finds substring                 |
===========================================================

=================================================================================
2.2 std::string (C++ Style):-
=============================
Introduced in <string> header, part of the STL.

#include <string>
#include <iostream>
using namespace std;

int main() {
    string name = "Manikanta Deepak";
    cout << name << endl;
}

Advantages:
✅ Dynamic resizing
✅ Operator overloading (+, ==, [], etc.)
✅ Rich API
✅ Safe and convenient

3. Common Operations on std::string
📍 Creation and Initialization
string s1 = "Hello";
string s2("World");
string s3 = s1 + " " + s2;

📍 Length and Capacity
cout << s1.length();
cout << s1.size();
cout << s1.capacity();

📍 Accessing Characters
cout << s1[0];
cout << s1.at(1);

📍 Adding / Removing Characters
s1.push_back('!');
s1.pop_back();

📍 Substring
string sub = s1.substr(0, 3); // "Hel"

📍 Searching
size_t pos = s1.find("lo");
if (pos != string::npos) cout << "Found at " << pos;
	
📍 Replace
s1.replace(0, 2, "Hi"); // Replace first 2 chars with "Hi"

📍 Insert / Erase
s1.insert(3, "World");
s1.erase(3, 2);

📍 Compare
if (s1 == s2) ...
if (s1.compare(s2) == 0) ...

📍 Convert Between String and Numbers
int n = stoi("123");
string s = to_string(456);

📍 Iterate Over String
for (char c : s1) cout << c << " ";

🧮 4. Memory Model of std::string

Internally uses dynamic memory allocation (heap).

Before C++11 → Copy-on-write (inefficient)
After C++11 → Short String Optimization (SSO)

✅ SSO: Small strings (usually ≤15 chars) are stored inside the object itself (stack) to avoid heap allocation.

| Feature           | C-Style (`char[]`)    | C++ `std::string`         |
| ----------------- | --------------------- | ------------------------- |
| Memory Management | Manual                | Automatic                 |
| Safety            | Unsafe                | Safe                      |
| Operations        | `<cstring>` functions | Built-in member functions |
| Dynamic resizing  | ❌ No                 | ✅ Yes                   |
| Comparison        | `strcmp()`            | `==`, `<`, etc.           |
| Exception Safety  | No                    | Yes                       |


⚡ 6. Advanced String Topics
🧩 6.1 String Views (std::string_view)

Introduced in C++17 — lightweight read-only view of string data (no copy).

string_view sv = "Hello World";
cout << sv.substr(0, 5); // prints Hello


→ Faster, used in performance-critical code.

🧩 6.2 Raw String Literals

Avoids escaping special characters:

string path = R"(C:\Users\Deepak\Desktop\)";

🧩 6.3 Unicode Strings

C++ supports:

std::u16string — UTF-16

std::u32string — UTF-32

std::wstring — wide characters

🧩 6.4 String Streams (<sstream>)

Used to treat strings like input/output streams.

#include <sstream>
stringstream ss;
ss << "Deepak " << 25;
string result = ss.str();

🧩 6.5 Mutable vs Immutable Behavior

Unlike Python, C++ strings are mutable.
You can modify characters directly:

string s = "Hello";
s[0] = 'Y';  // "Yello"
