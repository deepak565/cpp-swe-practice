# 🔹 COMMON TRAPS INTERVIEWERS CHECK

❌ Uninitialized min/max
❌ Wrong loop variable in inner loop
❌ Assuming square matrix
❌ Using `sizeof` inside function
❌ Out-of-bounds access
❌ Forgetting to pass row/column sizes

---

# 🔹 HOW TO ANSWER AS A 5+ YEAR ENGINEER ⭐

When coding, **say this out loud**:

* Time complexity
* Space complexity
* Edge cases
* Why you chose this approach

Example:

> “This solution runs in O(R×C) time with O(1) extra space and handles rectangular matrices safely.”
